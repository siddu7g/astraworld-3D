# Code Of Conduct

## Our Standard

We want `WorldForge-3D` to be a respectful, constructive project for maintainers, contributors, and users.

Examples of positive behavior:

- giving actionable technical feedback
- assuming good intent
- documenting reproducible steps
- staying honest about limitations and tradeoffs

Examples of unacceptable behavior:

- harassment, insults, or intimidation
- bad-faith arguments or repeated hostility
- publishing private or sensitive information
- spamming issues, reviews, or discussions

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, commits, code, or other contributions that violate this policy.

## Reporting

Report conduct issues to the project maintainer through the repository contact channels. Include links, screenshots, or reproduction context where relevant.

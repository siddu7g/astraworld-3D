# Launch Notes

Use this checklist when publishing or refreshing the public repository.

## GitHub Metadata

- Name: `WorldForge-3D`
- Short description: `Open-source 3D world generation bridge for Marble, OpenUSD, and Isaac Sim`
- Suggested topics:
  - `openusd`
  - `isaac-sim`
  - `marble`
  - `gaussian-splatting`
  - `world-generation`
  - `omniverse`
  - `simulation`

## Citation

- Keep `CITATION.cff` up to date
- Connect GitHub releases to Zenodo for DOI-backed citations
- Update `AUTHORS.md` before tagged releases

## Best First Outreach Targets

1. `Isaac Lab` sample or docs integration
2. `usd-convert-gsplat` / `3dgrut` interoperability notes
3. `nerfstudio` / `gsplat` companion workflow docs

## Public Positioning

Lead with:

- prompt to world workflow
- practical Marble-to-Isaac bridge
- honest distinction between showcase rendering and simulation integration

Avoid leading with:

- construction-only framing
- claims of perfect reconstruction fidelity in Isaac
- claims of broad simulator support that are not documented
